## ビルド：「サイランプ」（量子意図検出器）
*目的：心と物質の相互作用を証明するランダムイベントジェネレーター（REG）。*

### 部品表（BOM）
* **マイコン:** ESP32（このチップのADCは notoriously ノイズが多い — エントロピーに最適）。
* **ディスプレイ:** WS2812B RGB LEDリング（または単一LED）。
* **電源:** USBケーブル。

### 物理学
「浮遊」アナログピン（Pin 34）を読み取ります。このピンは宇宙の背景ラジオ静電を拾います。最下位ビットを「コイントス」として使用します。「赤」に集中し、偶然以上にランプが赤くなる場合、波動関数を崩壊させています。

### コード（MicroPython）
```python
import machine
import neopixel
import time
import random

# 設定
PIN_NOISE = 34  # 浮遊アナログピン（ここには何も接続しない）
PIN_LED = 2     # WS2812データに接続されたピン
NUM_LEDS = 1

# セットアップ
adc = machine.ADC(machine.Pin(PIN_NOISE))
adc.attens(machine.ADC.ATTN_11DB) # フルレンジ
np = neopixel.NeoPixel(machine.Pin(PIN_LED), NUM_LEDS)

def get_entropy():
    # ADCを複数回読み取り、最下位ビットを取得
    raw = adc.read()
    # 最下位ビットが最もランダム
    return raw & 1 

def update_lamp(color):
    for i in range(NUM_LEDS):
        np[i] = color
    np.write()

print("サイランプ作動中。意図に集中してください。")

# 変数
balance = 0 # 0は中立。正は赤、負は青。

while True:
    # 1. 熱ノイズから「コイントス」を生成
    bit = get_entropy()
    
    # 2. 結果を蓄積
    if bit == 1:
        balance += 1
    else:
        balance -= 1
        
    # 3. 可視化ロジック（減衰）
    # 「エントロピー」を表すため、バランスをゆっくりゼロに戻す
    if balance > 0: balance -= 0.1
    if balance < 0: balance += 0.1
    
    # 4. 表示
    red_val = 0
    blue_val = 0
    
    if balance > 5:
        red_val = min(255, int((balance - 5) * 10))
    elif balance < -5:
        blue_val = min(255, int((abs(balance) - 5) * 10))
        
    update_lamp((red_val, 0, blue_val))
    
    # 高サンプリングレートのための高速ループ
    time.sleep(0.01)
```
使用方法：机に置く。心を集中させる。「赤」を視覚化する。オメガ9物理学によれば、「ノイズ」は意識の周りに自己組織化します。
